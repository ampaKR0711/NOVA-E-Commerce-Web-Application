# 🛍️ NOVA

### Modern E-Commerce Web Application

> **NOVA** is a responsive and interactive e-commerce web application designed to simulate a complete online shopping experience — from discovering products and applying filters to managing a wishlist, shopping cart, checkout, simulated payment selection, order confirmation, and order history.

---

## 🌐 Project Overview

**NOVA** is a frontend-focused e-commerce web application developed to demonstrate how modern web technologies can be combined to create a complete digital shopping workflow.

Instead of functioning as a simple product catalogue, NOVA brings multiple e-commerce features together into one unified customer journey.
